# 按实际日期核对个人资金回报

第 12 项以同一账户范围和汇总币种计算资金加权收益率，采用 XIRR 的实际天数 / 365 年化约定，并将同一个解按估值基准至期末的实际天数换算为区间回报。期初收盘资产视为负投入，期间外部投入为负、外部撤回为正，期末资产视为正回收；内部买卖、范围内转账及分红应收转现金不额外形成外部资金流，费用留在净资产中。

期初沿用共同可核对收盘边界；自定义区间已有更早起点时以前一日收盘为估值基准，界面同时显示请求区间、实际基准及天数。范围内实际资金流以其原始记录日期参与折现，跨币种资金流使用该日可核对汇率；不改写实际换汇账务。仅依赖基准、期末证券估值及资金流日期汇率，区间中无关的证券价格缺口不应阻止资金回报。

起点或期末缺价、资金流汇率不足、无有效起点本金、零天区间及没有有限解时保留原因和计算明细，不用 0% 补齐。多次变号的资金流必须确认解的唯一性；多个解或数值条件无法可靠区分时不给出任选的年化数值。所有金额保持整数分，汇率沿用既有定点换算；求解与展示回报使用数值算法，不将浮点金额写入账本。

来源：https://support.microsoft.com/en-us/excel/functions/xirr-function ，https://help.portfolio-performance.info/en/concepts/performance/money-weighted/ 。

默认区间截至所需端点来源已完成收盘时段的日期，避免当日 FX 日线永远未完成而使默认页始终无法计算；使用已缓存的明确交易日映射核对实际 session，回退后重建当日持仓/币种与资金流范围。只按来源时段回退，不因真实缺价反复寻找旧值，未知日历仍保留缺项；原币纯现金不无谓回退。页面显示实际截止日和天数，自定义日期不自动改变。
