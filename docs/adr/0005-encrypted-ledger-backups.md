# 使用 age 加密完整逻辑快照并以事务恢复账本

2026-10-25，主线第 2 项采用 age 密码加密格式，内部 Graham 备份版本独立于软件版本。备份保存同一读取事务中的全部账户、入金、历史及账户配置与版本序号；不复制运行中的数据库主文件，不将密码或明文备份写入磁盘。逻辑格式让输入可以先在独立内存账本验证引用、历史和金额，再接触当前账本，代价是未来增加持久化实体时必须同步演进备份格式与兼容策略。

恢复前的当前账本快照与替换处于同一个即时事务范围，保护并发写入之间的间隙。先将当前快照使用本次输入的密码加密保存到用户数据目录的备份子目录，保存失败则中止；随后整体恢复并提交，失败回滚。恢复前副本可以通过相同备份入口恢复，用户仍需保管密码；当前本机 SQLite 不加密的既有决定不变。

恢复会保留业务记录身份和全部历史内容、时间及顺序，但重新分配内部修订句柄，使其均高于当前账本曾使用的编号，避免另一窗口的旧选择、历史恢复或撤回被错误接受。新编号按实际恢复历史数量连续分配，不将备份中的计数值累加回当前计数，避免反复备份恢复导致编号加速膨胀；结果快照在同一事务提交前生成，提交后不再进行可能失败的额外数据库读取。
