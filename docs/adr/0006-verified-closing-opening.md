# 用账户收盘期初衔接不完整历史

第 4 项（Issue #5）按账户保存一个可核对日期的收盘状态，直接记录现金、各证券数量、已核对剩余总成本及可选的该日期参考价格。它是计算起点，不伪造买入或入金，不将快照金额计作新增投入，也不反推此前已实现收益。

有效快照覆盖该日及以前的全部记录：原始记录和历史仍保留可查，但不再次计入；次日起的记录接着移动平均成本及现金时间线核算。同日收盘口径避免半日快照与当日交易先后不明造成重复。修改起点日期会改变覆盖范围，因此界面必须重新确认范围，后端重算全部后续依赖，失败整体回滚。

日期早于有效期初的查询返回缺失原因和空金额，不把未知余额或表现伪装为零。没有期初但有完整手动记录时沿用原有时间线；查询早于最早记录或无记录则说明无核对起点。后续收益曲线任务复用此边界，不在本项生成虚构历史曲线。

剩余总成本必须由用户核对后录入；期初参考价可以缺失，缺失时明确期初估值数据不足，成本不充当市场价。账户仅接收原币与账户一致的证券，跨币种结算由换汇任务处理。

每个账户保留一个当前快照及其修订历史；作废会重新启用原有时间线，因此也要检查超卖、现金不足及溢出。沿用既有纠错习惯，支持修改、历史恢复、可恢复删除，以及仅作废后的文字确认彻底删除。彻底删除是 ADR-0004 同一明确清除规则对手动期初记录的扩展，不触及独立备份；导入的关联快照另行设计。

数据库升级为 v4，升级已有 v3 前保存一致迁移快照；加密备份格式升级为 v3/schema4，兼容旧 v1/schema2 与 v2/schema3，并包含期初及历史。恢复重新分配期初修订句柄，拒绝另一窗口持有的旧选择及旧版本。
