# 为已作废手动入金提供不可恢复的彻底删除

2026-10-25，用户确认在保留普通删除为可恢复作废的基础上，为已作废的手动入金新增单条和批量彻底删除，同时清除该记录的全部修改历史，软件内不再提供恢复或撤回。这是 ADR-0002 保留原始记录和修正来源原则的明确例外：用户选择以失去这部分核对依据为代价清除错误记录；操作必须展示所选范围和条数，明确不可恢复，并输入“彻底删除”确认。

独立备份及升级快照不随之清除，也不承诺磁盘安全擦除。本次例外仅覆盖现有手动入金，未来导入及关联交易仍按各自规格处理；普通作废继续保留原始内容和历史。

用户随后确认，账户最后一条记录及历史被清除后重新按空账户处理，允许改币种或删除账户，不额外保留“曾有历史”的永久限制。

用户随后要求为手动买卖补充彻底删除（Issue #21）。将同一例外扩展到已作废的单条手动买卖及全部修订历史，仍要求显示账户、条数和证券范围、输入确认文字、拒绝过期版本，原子清除且不可撤回。交易已经作废，因此彻底删除不再次影响现金、有效持仓、成本或盈亏。最后一条记录及历史清除后的空账户规则同样适用；导入关联记录及交易批量操作另行交付，独立备份保留。

## 2026-10-27：改为直接点击执行（Issue #22）

用户明确要求移除确认文字，点击“彻底删除”即执行。本次更新取代上文及早期 PRD 中的文字输入和二次确认要求，覆盖现有手动入金单条/批量、手动买卖、期初快照、关联转账/换汇和分红。入口仍仅在已删除记录中出现；后台版本校验、依赖检查及原子事务不变，成功仍清除全部历史且不能撤回。普通作废及独立备份规则不变，未扩展到导入记录的彻底删除。
