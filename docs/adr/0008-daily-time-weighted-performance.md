# 用日频约定计算可核对投资表现

第 11 项按同一账户范围、汇总币种、逐日估值与外部资金流计算时间加权收益率。现有记录只有日期，选择入金按日初、出金按日末的约定，逐日链接 `(期末资产 + 外流) / (前日资产 + 流入)`；界面明确说明它不是按真实日内时点逐笔估值。共同可核对起点的收盘是基准，不能反推其当日及更早收益；选定区间已有较早起点时以前一日收盘为基准。无参与计算本金的日期不伪造收益率。

估值包含现金、持仓及税后分红应收，分红到账只把应收转为现金；采用未复权价格，内部转账在合并范围不计外部资金流，手续费保留为损益。Yahoo 历史 Close 仍可能受后续拆股影响，无法核对的拆股以前价格停用，不能将其与旧持股数量相乘。

日历固定为内置 exchange_calendars 4.13.2 的 XSHG/XHKG/XNYS，休市日期明确展示所参考的上一交易日收盘。外汇使用已说明的工作日约定，缺少该日汇率仍显示缺项。日历不支持的范围、缺价、未完成收盘及不可核对起点均保留原因；累计曲线遇缺口后断开，不用零、成本、其他日期或重新起算掩盖。第 10 项的指定日期严格估值规则保持不变。

每次计算冻结账户记录的一致内存副本，市场缓存另库处理；后台网络请求不持有账本锁，按来源区间分批、退避、允许暂停，查询与修正记录不会写入个人账务。收益率以固定小数逐日链接并展示六位小数。

日频约定参考：https://help.portfolio-performance.info/en/concepts/performance/time-weighted/ 。交易日历来源：https://github.com/gerrymanoim/exchange_calendars 。
