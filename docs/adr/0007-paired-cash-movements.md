# 以关联两端记录转账与换汇

第 5 项（Issue #6）将一次内部转账或换汇保存为单条关联记录，包含两个账户、日期、两种原币本金、实际汇率和单列手续费。转账要求币种相同、本金相等、汇率为 1；换汇要求币种不同，汇率采用“1 单位转出币种对应多少转入币种”，最多八位小数，折算本金四舍五入到分后必须等于录入的转入本金。不自动用市场汇率代替实际成交汇率。

手续费可以指定由转出或转入账户扣除：转出实扣为本金加转出端手续费，转入实收为本金减转入端手续费。录入的本金不含手续费，界面展示实扣/实收供核对；同一费用仅在选择的一端扣一次。所有金额采用原币整数分，汇率使用定点数及 i128 中间值，跨币种金额不直接加总。

每条记录的两端在同一事务写入、修改、作废、恢复和彻底删除，先验证完整时间线再提交。修改不允许更换两端账户，账户选错时先整笔删除再重录。普通删除保留全部历史并可撤回，已作废记录输入确认文字后可整笔清除及全部历史；独立备份保留。两端任一账户仍有记录或历史都保持币种/删除保护。

资金流分类随所选账户集合改变：两端都在范围内时不增加合并外部投入；只含转出端是范围外流，只含转入端是范围流入。手续费作为费用单列，不伪装成追加/撤回本金。核对按日期范围分别返回 CNY/USD/HKD，范围包含期初当日或此前时明确数据不足，不输出正常零值。收益率及多币种估值仍由后续任务实现。

现金同日先入金，再将买卖和转账换汇按首次录入的统一顺序处理，允许卖出后转账。迁移时既有买卖按旧顺序编号；修改和恢复保留顺序。期初分别覆盖每个账户该日及以前的现金端，不强行再次扣/加另一端；原始关联仍保留供核对。

数据库升级到 v5，已有 v4 升级前保存一致迁移快照。加密备份 v4/schema5 包含关联记录、修订历史及跨类型顺序；兼容旧 v1/v2/v3，旧买卖按备份中的既有顺序编号。恢复保留业务顺序，重新分配各类内部修订句柄，拒绝旧窗口的选择和撤回。
