# 按可核对资产和原币证券盈亏分析组合

第 13 项复用一致账本内存副本、证券身份和估值来源，按账户/合并范围、当前参考或明确历史日期分析。分布包含现金、证券及待到账分红，市场/币种/行业/证券分组均保留所有图例，缺项不以成本或零代替市值；占比只按已知资产计算，明确缺项数量，不冒充完整组合占比。

证券贡献按各账户收盘期初以后累计的已实现、未实现及已确认税后分红计算；期初当日及以前不回推分红或已实现收益，分红由应收转现金不再次计入。已清仓和仅分红证券仍保留明细。原币证券盈亏按所选估值时点汇率逐项折算，正负金额先按绝对值定点换算再恢复符号，避免负值舍入偏差。这里只汇总证券贡献，不等于完整账户净收益或收益率贡献；非证券转账费用及现金/实际换汇汇兑盈亏不混入证券归因。

持仓缺价、缺汇率或起点不可核对时，保留原币已知数与原因，整条证券明细不参与已知贡献金额和条宽归一化；完整已清仓证券无需现价。贡献按证券身份跨账户归集，正负金额分别标示，条宽为已知净额绝对值占比；明细仍按账户核对。

行业采用带公司一手资料来源的本地业务分类（核对 2026-10-27），不声称 GICS/申万或历史时点行业分类；未覆盖保留未分类，基金仅按登记类型注明未穿透。该公开资料目录随应用发布，不是用户交易或配置，无新增金融表和备份格式。证券身份继续用于核算与行业分类。2026-10-27 用户取消证券 Logo 系统后，证券改以名称与代码等文字展示，不再提供品牌图像或占位图标；Graham 自有品牌不受影响。
