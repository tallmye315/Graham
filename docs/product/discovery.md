# Graham 需求访谈记录

状态：Q1—Q26 产品选择与 PRD 主要验收边界已获用户认可；进入 PRD 发布和页面原型阶段。

## 已确认的目标

- 项目名称：Graham。
- 观察美股、A 股和港股持仓。
- 计算收益率，记录和分析分红，绘制收益率曲线。
- 组合分析的含义见根目录 `GLOSSARY.md`。
- 页面布局尚未确定，通过后续使用场景和原型讨论明确。

## 第一轮已确认

用户确认 Q1—Q6 均采用建议：

1. 第一版面向个人投资者，提供本地记账与投资分析。
2. 第一版支持 Windows 桌面安装和使用。
3. 导入券商交易记录，支持手动补充和修正；记录买卖、入金、出金与分红，后续考虑自动连接券商。
4. 尽量导入历史记录，还原历史投资表现；历史覆盖不足时的处理方式待讨论。
5. 个人投资记录保存在本地，支持备份和恢复；行情与汇率通过网络更新。
6. 第一版组合分析覆盖资产分布和收益贡献。

## 第二轮已确认

用户确认 Q7—Q10、Q12—Q13，并修改 Q11 的建议：

7. 不同券商账户分别记账，同时提供合并总览；同一证券可分别或合并查看。
8. 第一版覆盖股票、ETF 和账户现金。
9. 总览默认折算成人民币，保留原币金额，并允许切换人民币、美元或港币作为汇总币种。
10. 新增本金单独记录，收益计算区分资金进出与投资盈亏；入金本身不造成收益曲线跳涨。
11. 盘中持续自动更新行情和估值。此前提出的“每日收盘数据加手动刷新估值”不再作为已确认需求；具体刷新目标和行情状态见后续已确认条目。自动刷新行情与自动同步账户交易是不同能力，账户交易仍按第一轮导入方案处理。
12. 首页优先展示总资产、投资盈亏、收益曲线和持仓分布，并可进入持仓、交易与分红明细。
13. 计划优先适配华龙证券、兴业证券的导出格式。具体客户端、市场覆盖、导出字段及历史跨度以经授权且已脱敏的样本验证；此处描述产品适配计划，不对应任何个人的开户或使用情况。当前专用格式尚未适配，使用统一 CSV 导入。

## 第三轮已确认

Q14—Q20 确定采用免费行情，付费订阅不纳入第一版范围：

14. 同时展示投资表现收益率与个人资金回报率，分别对应时间加权和资金加权的观察目的，以中文解释差异。
15. 默认盈亏扣除已记录的实际税费；分红保留税前金额、扣税、实收与待到账状态。
16. 不同投资账户之间的转账在合并总览中属于内部转账；单账户保留进出记录，转账手续费单独计入。
17. 交易时段内以约每 5 秒更新持仓估值为目标；实际报价时间和权限由行情源决定，页面展示报价时间和连接状态。
18. 第一版采用免费行情方案，暂不接入付费订阅。
19. 断线或缺乏权限时保留最后一次有效估值，明确显示延迟、断线或缺失状态；缺失价格不记为零，历史记录仍可查看。
20. 页面从浅色桌面仪表盘开始：左侧导航，上方资产和盈亏，中间收益曲线，下方持仓分布；通过可点击原型进一步调整布局。

## 第四轮已确认

用户确认 Q21—Q26 均采用建议：

21. 历史记录不完整时，从最早可核对日期建立期初持仓和现金；收益曲线从可验证日期开始，此前收益标记为数据不足。
22. 文件导入经过预览、校验和确认入账，识别重复记录，列出错误行并在修正后入账。
23. 免费实时权限不足时接受明确标记的延时行情；没有有效延时报价时，显示最后有效价格或手动价格及其日期。
24. 历史资产曲线采用对应日期的汇率；实际换汇使用交易记录中的金额和汇率，并保留原币表现。
25. 以交易流水计算持仓成本，默认移动加权平均成本，分别展示已实现和未实现盈亏；与券商展示不一致时提供差异核对。
26. 第一版历史收益曲线按日绘制，支持近一个月、今年以来、全部及自定义日期；盘中持仓估值仍以约 5 秒刷新为目标。

## 行情约束与待验证条件

- 三市场免费数据源的覆盖、时效、限频及稳定性需要分别实测，不以个人行情账号的权限作为产品保证。
- “每 5 秒更新估值”是产品更新目标，不代表行情源提供每 5 秒产生的交易所实时数据。
- 免费源不能满足实时要求时，用户已接受明确标记的延时行情；无有效报价时使用最后有效价格或手动价格，始终显示日期和状态，不得将旧报价显示为实时。
- 账户交易仍通过导入和手动修正更新，不因行情自动刷新而获得账户自动同步能力。

## 设计树：后续阶段的验证与细化

- 数据适配：使用经授权且已脱敏的券商导出样例，确定字段、市场、交易渠道和历史跨度；公开示例仅使用合成数据。
- 账务边界：根据记录类型明确证券转入转出、公司行动、分红确认日和特殊账务事件的规则；未知记录进入待处理状态，不静默入账。
- 计算验证：落实时间加权与资金加权算法、资金流时点、税费归属、汇率与成本计算，使用可核对样例验证。
- 行情验证：测试免费账号实际权限、市场覆盖、报价时效、限频及历史数据能力。
- 原型评审：验证信息密度、曲线可读性、导入校验和异常提示。
- 桌面工程：落实已确认技术方案，验证本地存储、加密备份恢复、运行时打包、安装和升级；在无系统 Python 的干净 Windows 环境验收。
