# 开发版纠错与品牌修改访谈

日期：2026-10-25。状态：用户回复“全部按建议”；本轮当前手动记录纠错、品牌及快捷方式已实现，并通过 0.1.1 安装升级验收。导入批次撤回留在 #8，验收证据见 `../development/record-correction-milestone.md`。

## 用户提出的问题与明确要求

- 填错信息或导入错误信息后，需要能够处理错误记录，并支持删除、撤回相关操作。
- 软件品牌使用用户截图中的蛇环 `Gra / ham` 短标与完整 `Graham` 字标组合；Windows 软件图标使用短标。
- 安装后需要桌面快捷方式，快捷方式使用相同短标。
- 品牌方向已在 `brand-logo-discovery.md` 记录。此处不将未验收的功能标记为完成。

## 已知规格约束

- PRD 已要求手动修正并追溯原始记录，ADR-0002 要求保留原始行、导入批次和修正来源。
- 因此需要明确用户界面的“删除”是否表示可恢复的作废，以及修改和撤回后如何保留核对依据；不能直接推导为永久清除原始账本记录。
- 当前已交付里程碑是账户建立、手动入金与本地持久化；CSV 和券商文件导入属于后续任务。本轮需区分当前记录纠错与未来导入批次撤回。

## 已确认的规则

1. 当前手动入金提供修改和删除。删除即作废、不参与余额计算，可在已删除列表恢复。修改保留旧值和操作历史。
2. 修改或删除后立即提供撤回入口；关闭软件后仍可通过持久化记录历史恢复旧版本。恢复也记入历史，不覆盖核对依据。
3. 账户可改名。有历史记录时锁定币种；无历史记录时可调整币种或删除账户。有历史记录的账户提供归档及取消归档，归档不改变合并资产或历史结果。
4. 下一安装包交付当前手动记录纠错、品牌与实际桌面快捷方式。单条导入纠错和整批撤回随导入任务交付；有关联记录时先提示影响，不能破坏关联账务。

## 本轮验收与测试边界

- 延用已确认的 Ledger 完整应用用例和少量界面流程边界；通过公开接口验证金额重算、删除/恢复、旧值历史、账户保护及重启持久化，不通过 SQL 查询验证内部实现。
- 无效修改或恢复导致金额溢出时，当前记录、余额和历史均保持不变。
- 旧版账本升级前保存一致快照，升级后原记录、原币余额和来源保留；迁移失败不以空账本替代原文件。
- 原生安装包升级保留数据；退出重启后仍能恢复记录；短标和完整 Logo 使用独立正式 SVG/ICO 资源，运行不依赖原型服务器。
- 安装器在用户桌面创建可用快捷方式，使用安装目录中的短标图标；同时提供软件内“创建桌面快捷方式”入口以便修复被删除的快捷方式。
- 当前不增加真实交易、CSV、行情或收益功能。
