# Graham 品牌 Logo 设计访谈

> 本文保留历史设计决策。旧原型和预览入口已退役；当前正式品牌资源见 `assets/brand/`。

状态：2026-10-25 用户以截图选定蛇环 `Gra / ham` 短标与蛇形 G 的完整 `Graham` 组合；已整理独立正式资源，并在 0.1.1 原生安装版核对完整主标、白底酒红短标、桌面快捷方式图标和重启显示。证据见 `../development/record-correction-milestone.md`。

## 已明确的要求

- 以单词 `Graham` 为设计主题。
- G、r、a、h、a、m 六个字母都要参与，包括两个不同位置的 a。
- Logo 沿用酒红 `#781D37` 与白色，准备白底酒红和酒红底白色版本。

## 第一轮已确认

用户确认 Logo Q1—Q4 均采用建议：

1. 主标识第一眼应能读出完整的 Graham，使用字母连接、共用笔画形成统一的定制字标。
2. 沿用软件酒红与白色配色。
3. 气质专业、克制、稳健，带一点经典金融品牌的特征，通过字形比例和细节体现个性。
4. 同时用于软件左上角与 Windows 桌面图标，分别验证横向和方形构图、小尺寸效果；每种形式都必须说明六个字母如何参与。

## 第二轮与蛇元素补充

用户确认 Logo Q5—Q7，并明确要求加入蛇元素：

5. 保留大小写 `Graham`，即大写 G、其余小写，两个 a 使用一致的字形语言。
6. 原先“仅由六字母表达”的建议被蛇元素要求修订：六字母仍是主体，蛇参与连接、共用笔画或整体构成。
7. 方形图标允许 `Gra / ham` 两行构图，并允许为小尺寸适当简化笔画；六字母全部保留。

本轮制作三个候选作为设计问题的可运行答案：克制的藏蛇连字、几何线条构成、蛇环徽记。蛇的具体位置和字形细节通过这些候选比较，不将某个候选预先当作最终选择。

## 设计树

- 字母表达：完整可读、`Graham` 大小写、全部六字母参与已确认；加入蛇的具体方式通过候选比较。
- 视觉气质与配色：专业稳健、酒红与白色已确认，具体笔画和字形通过候选视觉方案比较。
- 使用场景：软件侧栏与 Windows 图标已确认，方形可采用两行 `Gra / ham` 并简化小尺寸笔画。
- 交付与验证：方向明确后制作候选，标明六个字母分别如何参与，并检查单色、反白与小尺寸效果。

访谈确认后再进入可视化设计；每个候选都必须能说明两个 a 在内的全部六个字母的对应关系。

## 2026-10-24 融合反馈

用户反馈：“B 的字母 G 设计很不错，我觉得可以融合到 C，C 的小尺寸图标很好”；补充：“C 方案的字母粗细很好”。

- 以 C 为融合基础，保留其粗衬线字形、酒红与白色、蛇环构图。
- 新增 D 融合稿，原 A/B/C 保留作为比较来源。
- 横版名称中的 G 沿用 B 的几何蛇形轮廓与开口蛇首，加粗匹配 C 的视觉重量；其余 `raham` 使用 C 相同字号、字重及字距规则。
- 方形图标及横版左侧徽记完整保留 C 的构成，避免改变用户已认可的小尺寸效果；其中仍为六个字母 `Gra / ham`。
- 评审入口：http://127.0.0.1:4173/prototype/graham?variant=A&page=settings&brand=D 。同一路由可切回 C 比较。
- D 提供原色、反白、深浅方形图标和字母拆解，共五个 SVG。当前共 20 个 SVG；最终品牌资源和 Windows 图标导出仍待定稿。

## 2026-10-25 用户选定

- 用户提供截图，明确软件 Logo 使用图中的完整组合：左侧蛇环内为 `Gra / ham`，右侧为带蛇形 G 的 `Graham` 字标；与 D 融合稿对应。
- Windows 软件图标使用左侧蛇环短标，保留六个字母，沿用白底酒红配色。
- 用户要求安装后提供桌面快捷方式，快捷方式使用同一短标。
- 本轮记录的是用户已确认的方向；正式 SVG/ICO 资源、软件内展示、快捷方式生成以及 Windows 图标缓存下的显示效果尚未验收。记录纠错与本轮修改范围见 `record-correction-discovery.md`。
