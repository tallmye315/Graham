# 今日与累计证券收益交付

对应 [Issue #27](https://github.com/tallmye315/Graham/issues/27)，规格见 `docs/product/today-profit-discovery.md`，决策见 ADR 0011。

版本 0.1.23：按市场、原币和账户核对今日盈亏及分类累计盈亏；未合并不同币种或不同交易日期的收益。现金独立显示，原账户投资表现曲线保持含现金口径。已清仓证券通过独立明细窗口查看，其已实现盈亏与分红仍保留在市场累计结果中。

## 测试

用户确认通过临时账本公开接口及完整页面交互测试，不使用真实账本作测试数据。

- 首个公开接口用例在 [40650618782](https://github.com/tallmye315/Graham/actions/runs/40650618782) 因新接口不存在而失败；补齐实现及符合原接口校验的合成美股日线后，在 [40651519789](https://github.com/tallmye315/Graham/actions/runs/40651519789) 通过。独立手算示例：十股成本 1000，昨收 110，当日卖四股 115、费用 2，余六股现价 112，税后分红 8；累计已实现 58、未实现 72、分红 8、合计 138；今日 38，证券回报率 3.454545%。
- 过期盘中报价不应冒充已核对收盘，测试先红于 [40651876722](https://github.com/tallmye315/Graham/actions/runs/40651876722)，修复后 [40652234208](https://github.com/tallmye315/Graham/actions/runs/40652234208) 通过。
- 页面交互用例先因总览不存在对应市场区块而失败，实现后通过，覆盖市场／原币分组、累计与今日拆分及清仓窗口。旧记录操作测试改为在桌面接口边界区分收益只读查询，原断言保留；本机共 35 项前端用例及类型检查通过。
- [40653392834](https://github.com/tallmye315/Graham/actions/runs/40653392834) 已通过首次买入、全部清仓、分红支付不重复计入及美股跨北京时间午夜的公开接口回归与前端检查。

## Standards

规范审查发现历史缓存失败原因丢失（P2）与历史响应解码重复（P3 判断性异味）。已保留当日／前收盘失败原因及 stale 状态，并抽取共用历史协议解码。复查新增问题 0。

## Spec

需求审查发现同一个来源失败状态缺陷（P2）；修复后复查新增问题 0。A 股部分来源缺少完整报价日期时继续明确参考估算，不将接收时间描述为交易所真实报价时间。
