# 第 6 项：分红记录（Issue #7）

## 范围与口径

手动记录股票/ETF 的已确认现金分红。确认日期用于分红登记，实际到账日期用于现金；待到账不增加现金，转为已到账仅更改同一笔记录，不再次确认分红或新增本金。不要求当前仍持有该证券：卖出后仍可能收到已确认分红。不推算应得股数、公告分红或代办税务。

税前金额大于零、扣税非负且不超过税前、净额必须等于税前减扣税，均最多两位小数。已到账必须填写不早于确认日的实际到账日期；待到账不保存到账日期。证券市场、币种与账户一致。

汇总按账户及证券分别展示税前、扣税、净额、待到账净额、已到账净额，并附原始记录 ID。汇总含已登记期初前历史，仅供分红核对，不冒充完整历史收益；不同币种分别展示，已删除记录不计入。实际到账日受账户收盘期初覆盖，与确认日分别判断。

沿用当前单条纠错：修改、历史恢复、可恢复删除、即时撤回、仅已删除后的确认文字彻底删除及全部历史。变更重算整条后续现金时间线，依赖已花掉的分红时拒绝删除或改成待到账；失败原子回滚。账户选错先删除再重录，不允许修改账户。
