## 验证边界

- 延续公开 Ledger 完整用例、完整 App 的外部 IPC 边界和已安装市场进程协议，不为内部组件另建测试体系。当前 70 项 Ledger 用例包含持久化、从旧账本迁移及可重开原始快照、加密备份/恢复与失败回滚、导入与去重、金融计算、缓存失败沿用等；30 项 App 测试及类型/构建检查通过。
- 延续 Windows CI 的 NSIS 安装、安装后内置运行时和快捷方式/窗口图标验证；从无关目录以空 PATH、无效 PYTHONHOME/PYTHONPATH 启动，系统 Python 不向该进程提供依赖。七个历史内置资源执行构建前完整性及安装后的解码检查；测试写入使用独立合成账本。
- 以上覆盖依赖隔离、内置资源和安装检查，不能证明已在完全断网、无 Python/WebView2 的干净 Windows 环境完成安装。严格独立环境验收尚未执行，保持待验证状态。
- 历史版本按原定门槛新增七个已核对 Logo 的缓存和主动更新。固定官方 HTTPS 来源及 SHA256 与内置目录逐项绑定；新增图像须人工核对并随软件更新校验清单。下载读取有限字节，校验通过后以同目录临时文件、fsync 和原子替换保存，失败不覆盖有效缓存。缓存独立于安装目录，可重建，不纳入账本迁移及加密备份。

## 使用与恢复

1. 保存或取消正在编辑的内容，从“备份与恢复”导出加密备份，妥善保管密码；关闭 Graham 后运行新版安装包。
2. 账本在 `%LOCALAPPDATA%/com.graham.portfolio/ledger.sqlite3`；行情缓存为独立 `ledger.quotes.sqlite3`，不在安装目录。本地账本和自动升级快照未加密。
3. 需要结构迁移时先保存 `ledger-before-vN-*.sqlite3` 一致快照，再以事务迁移；启动失败不要删除数据目录。0.1.18 → 0.1.19 不触发结构迁移。
4. 加密备份通过页面先验证再确认整体恢复，恢复前自动保存当前账本的加密副本。失败保留原数据和恢复路径；不要用仍在运行中的数据库文件覆盖账本。

## 当前限制

- 华龙、兴业专用导出格式延期；无券商自动登录、交易同步或下单。统一格式详见 [unified-csv.md](../product/unified-csv.md)。
- 免费行情可能延时、限频或不可达；约 5 秒是界面读取缓存频率，来源抓取和真实报价时点另列，不保证交易所实时行情。既有来源实测见 [market-source-validation.md](market-source-validation.md) 和 [quotes-us-milestone.md](quotes-us-milestone.md)。
- 历史缺价/汇率、不可核对起点明确不足；未自动登记拆股等公司行动，遇到数量/价格口径变化需核对。原币成本与个人记录不由行情覆盖。
- 行业是带公开依据的本地业务归纳，未知保留未分类、ETF 未穿透。证券贡献不等于包含所有现金费用与汇兑归因的完整组合收益率。
- Windows x64 当前用户安装、手动升级；无云同步。本轮不提供代码签名证书，系统可能显示未知发布者。

## 严格干净 Windows 的待执行步骤

在独立测试机或虚拟机建立初始快照，按照以下步骤验收。

1. 记录 Windows x64 版本，确认已安装软件、Python 注册项及可执行路径均没有系统 Python，EdgeUpdate 注册项和运行时目录没有 WebView2。初始账本为空。
2. 从另一环境复制最终 NSIS 安装包，核对本文记录的 SHA256；断开测试机网络，在没有开发服务器的条件下安装，观察随包 WebView2 离线安装分支确实执行成功。
3. 从桌面打开 Graham，在“版本与使用说明”核对最终版本、完整 Graham 品牌可见，证券为纯文字且无 Logo 更新入口；行情无网络时有明确失败或缺项，不伪装正常报价。
4. 仅在该独立空账本创建明确的验收账户及入金，保存、关闭、重开确认；重新运行安装包，核对账户、历史、缓存及图标仍保留。
5. 保留安装/启动结果、离线状态、七图显示和升级前后记录证据。环境或任一步缺失时保持该验收项未通过，不能用依赖隔离检查替代。
