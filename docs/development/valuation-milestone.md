## 范围与计算

新增多币种估值页，默认人民币，切换美元 / 港币和账户范围（全部含归档）不写原币账本。当前资产基于北京时间记账日期对应的账户状态、最后有效证券报价及参考汇率。历史查询按账户起点和交易日期计算数量 / 现金，价格与汇率精确匹配所选日期，不用今日或相邻日补齐。未到起点、价格或汇率缺失分别列明；只展示已知小计，完整总额与占比留空。

资产包含现金、仍持有证券的原币市值和已确认未实际到账的税后分红。分红按实际到账日由应收转为现金，不重复计算。原币现金纳入币种分布，保留原币现金 / 证券 / 应收分项。原币价值先按既有整数分口径核算，再逐项采用 i128 定点中间量、八位参考汇率、四舍五入到分，汇总与展示明细一致；溢出明确显示不足，不伪造完整总额。实际换汇始终使用原记录的两端本金 / 手续费，参考汇率仅用于资产展示。

参考汇率为 1 USD 对 CNY / HKD，交叉币对使用对应两腿汇率，不引入 1:1 替代。每个日期和最新参考分别缓存，记录来源、原始时点、接收 / 尝试时间。日线按各市场时区；CN / HK / US 分别需经过 15:15 / 16:30 / 16:30 常规收盘缓冲，FX 只接受早于当前 UTC 日的日线，避免将未完结当日值称作历史收盘。此规则不替代完整交易所节假日日历；休市没有该日数据就显示缺项。

A 股股票 / ETF 和港股历史优先 AKShare 新浪未复权日线；美股 yfinance auto_adjust=false / back_adjust=false / repair=false，确认目标日后至当前没有拆股事件才接受历史 Close。若后续拆股或拆股校验缺失，显式使该日期旧价格缓存失效并暂列缺项，不将已按拆股调整的价格直接乘旧数量。新页不宣称投资收益率、实际成交汇率或可成交净值；当前不同时点 / 旧值提示独立展示。

独立行情缓存 schema2 新增 valuation_data，沿用来源级在途租约 / 失败退避与 85 / 90 秒进程上限。最新 FX 与历史请求分别保存租约 / 限频，避免切换历史日期被最新汇率的五分钟周期阻塞；最新 FX 最短 300 秒、历史请求最短 60 秒，失败退避到 15 分钟。每批最多 10 项，按最久未尝试轮转。界面约 5 秒读取当前估值缓存，后台在当前自动刷新开关下为有非零资产的当前范围同时更新两组 FX，切换三种汇总币种均能继续更新；历史与诊断只显式刷新。金融主库 schema7 和加密备份 v6 不变，市场缓存不写入金融备份。新 DatedAccount 仅增加应收与起点信息的查询字段。

官方资料：[AKShare 股票历史](https://akshare.akfamily.xyz/data/stock/stock.html)、[基金接口](https://akshare.akfamily.xyz/data/fund/fund_public.html)、[yfinance history](https://github.com/ranaroussi/yfinance/blob/main/yfinance/scrapers/history.py)。保留既有精确依赖锁 / 下载哈希与许可，无需用户配置系统 Python。
