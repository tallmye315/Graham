# 第 5 项：转账与换汇

对应 Issue #6、PRD AC09/AC10，基准 `f43af49`（已交付 0.1.8），交付版本 0.1.9。

入口“转账与换汇”按两个账户记录同币种转账或跨币种实际换汇，显示两端本金、实际汇率、手续费和实际扣款/实收。手续费可指定在转出或转入端扣除，本金均不含手续费。不同币种分别展示，不将换汇当作自动获取估值汇率。

两端是一条关联记录，写入、修改、删除、恢复及彻底删除始终整笔原子处理。修改不能更换两端账户，选错账户先删除后重录。普通删除保留历史并可撤回；彻底删除只处理已作废记录，展示两个账户、条数和金额并输入“彻底删除”确认。两端任一账户的记录或历史未清除前保护币种和账户删除。

核对资金流时选择一个或全部账户及日期范围；内部配对不增加合并外部本金，单端按范围流入/流出，手续费单列为费用。包含期初当日或此前的范围明确数据不足。资金流核对仅解释本金和本项费用，不宣称已实现收益率或跨币种完整估值。

现金时间线同日先入金，买卖和转账换汇按首次录入的统一顺序处理，支持卖出后再转出。期初各自覆盖账户对应一端，旧记录不重复计入。实现及兼容选择见 ADR-0007。验收用独立临时账本，不操作个人资金记录。
