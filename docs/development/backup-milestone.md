# 加密备份与恢复

状态：0.1.5 已实现、通过验收并在本机安装。规格：[主线第 2 项 / Issue #3](https://github.com/tallmye315/Graham/issues/3)、PRD AC21、ADR-0002。

沿用已认可的测试边界：Ledger 公开应用用例使用临时账本和文件，核对账户、记录、历史、账户配置和重启后的结果；少量 React 流程在外部 Tauri IPC 边界替换响应，验证密码输入、取消、摘要和确认。不会在个人账本试验恢复。

## 实施边界

- 备份包含当前已持久化的账户名称、币种、归档状态、全部手动入金（含已作废记录）、版本历史及版本编号。临时页面筛选与选择状态不属于持久化配置；未来新增持久化配置时需升级备份格式或明确纳入范围。
- 使用 age 密码加密格式及其现有 Rust 实现，内部 Graham 格式带版本和创建时间。完整解密并验证内容、引用和余额后才允许替换；对输入大小及解密工作量设置边界。
- 导出设置并重复输入至少 12 个字符的密码，软件不持久保存密码，不覆盖已有文件。导出最终文件只写密文，不写明文临时备份。
- 先验证备份并展示摘要，再明确确认整体替换当前账本；文件在预览后改变时拒绝恢复。恢复前在本机备份目录保存当前账本的加密一致快照，使用本次输入的密码，失败则停止恢复。
- 当前账本一致快照与替换覆盖同一个写事务范围，阻止并发写入落在未保护的间隙；恢复失败时当前记录、历史和配置全部不变。恢复成功后清空旧筛选、选择、历史和撤回状态。
