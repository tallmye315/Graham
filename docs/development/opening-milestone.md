# 第 4 项：期初快照

对应 Issue #5、PRD AC07，基准 `b09586e`（已交付 0.1.7）。

入口“期初快照”：按账户核对日期收盘现金及持仓数量、剩余总成本，参考价格可选。保存前展示覆盖的有效记录条数并要求勾选确认。每个账户只有一个当前快照，旧记录保留；界面资金及买卖列表注明“期初已覆盖，不重复计入”。

期初不是入金或买入。后续从次日衔接现金、成本及已实现盈亏；起点前数据不足，历史账本核对返回明确缺失原因，不展示 0 伪装已知。现有行情、收益曲线和两类收益率仍由后续任务交付；期初参考价不作为最新报价。

支持修改、历史恢复、撤回、可恢复删除和仅已删除时输入确认文字彻底删除。所有改变均校验后续时间线并用修订号拒绝旧请求。仍有快照历史时账户币种和删除保护保持，全部记录及历史清除后重新按空账户处理。

存储和备份边界见 ADR-0006。最终功能提交 `83203b495aa8387a782634d5af891f1866b85972`，验收流水线 [40259184724](https://github.com/tallmye315/Graham/actions/runs/40259184724) 全部通过：Linux/Windows 各 30 项公开账本测试、17 项界面测试、类型检查、资源检查、Windows 构建、实际安装及图标回归。

独立用例核对：期初现金 1,000、100 股总成本 1,500，旧入金 5,000 被覆盖但保留；次日卖出 40 股、单价 20、费用税款合计 3，剩余 60 股成本 900、已实现 197、现金 1,797。起点前查询返回空金额及数据不足。另验证修改依赖失败回滚、重复证券/非法金额拒绝、覆盖历史金额不影响当前溢出检查、空账户保护、历史清除、备份兼容、旧句柄失效与恢复前副本。
