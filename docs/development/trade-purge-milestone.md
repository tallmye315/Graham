# 手动买卖记录彻底删除

对应 Issue #21，版本 0.1.7，基准为已交付的 0.1.6 提交 `90008c9`。

“买卖与持仓 → 买卖记录 → 已删除”提供单条彻底删除。弹窗展示账户、1 条记录、证券、成交日期和数量价格；明确清除全部历史且不能恢复或撤回，输入“彻底删除”才能确认。有效交易仍需先普通删除，依赖检查继续生效。

后端以即时事务核对当前修订号和作废状态，清除该交易及全部历史，同一事务生成快照后提交。不重置修订号序列，不改变原有备份格式或数据库结构。已恢复、已修改、缺失和过期请求均拒绝，失败回滚。独立备份及快照保留，之后导出不再包含被清除记录；不承诺安全擦除。

成功后界面清空旧撤回和历史入口；失败保留错误原因，支持刷新后重新选择。全部历史清空的账户重新按空账户处理。当前交付单条手动买卖，交易批量功能和未来导入关联记录另行处理。

测试沿用已确认的公开 Ledger 用例和外部 Tauri IPC 界面流程，不在个人账本操作验收数据。后端用例覆盖有效/过期/已恢复/缺失拒绝、现金和持仓成本不变、其他交易和历史不变、清空账户保护解除、备份保留、新备份不含目标记录，以及重启后历史/撤回无法重建。界面用例覆盖两步删除、取消、严格文字确认、错误提示、刷新和成功移除撤回。
