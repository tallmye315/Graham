# 第 3 项：买卖与成本

对应 Issue #4、PRD AC11/AC12，开发版本 0.1.6。

## 交付范围和口径

- 手动记录 A 股、港股、美股的股票或 ETF 买卖；保留原币、市场与代码、实际费用、税款、日期、来源和备注。
- 唯一证券身份为市场加代码，股票或 ETF 类型是该身份的属性。A 股六位代码、港股五位代码、美股大写代码。账户币种必须与交易原币一致；跨币种结算等到换汇任务，不推测汇率。
- 数量和单价最多六位小数，费用和税款最多两位；输入使用十进制字符串，计算使用整数及 i128 中间值，不使用浮点。
- 成交金额四舍五入到分；买入成本包含实际费用及税款，卖出净收入扣除实际费用及税款。按成交日期排序，同日买卖维持首次录入顺序，修改不改变顺序；同日入金先于买卖。界面提示同日存在多笔交易时按实际先后录入。
- 卖出结转成本按卖出数量占卖前数量的比例四舍五入到分，余数留在剩余持仓，清仓结转全部剩余成本。单位成本保留六位小数，仅用于展示，后续计算使用剩余总成本。
- 拒绝超卖、现金不足、超范围和身份冲突。修改、删除和恢复会重算完整时间线，若破坏后续交易，整次操作回滚。
- 买卖支持修改、可恢复删除、历史版本和立即撤回，使用当前修订号拒绝过期操作。交易暂不提供彻底删除和批量操作；手动入金既有功能保留，删除入金也会核对交易依赖。
- 按账户展示持仓与累计已实现盈亏，清仓证券保留已实现结果。行情任务尚未实现；提供明确标记、不保存行情的手动价格试算，展示该输入下的市值与未实现盈亏，不把成本或成交价当作最新报价。

## 持久化和兼容

数据库迁移到 v3，升级 v2 前保存一致的本地迁移快照。完整加密备份格式升级为 v2/schema3，包含买卖及全部历史；仍接受 0.1.5 的 v1/schema2 备份。恢复旧备份是整体替换，会移除当前新增交易，但恢复前加密保护副本包含它们。恢复后重新分配交易修订号，旧窗口句柄失效。
