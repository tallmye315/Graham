# 第 12 项：个人资金回报（Issue #13）

个人资金回报页面按账户/合并范围、CNY/USD/HKD、近月/今年以来/全部/自定义区间核对年化 XIRR 和同解换算的区间回报，展示基准、期末和每笔外部投入/撤回日期金额及缺项来源。沿用 ADR-0009，年化采用实际天数/365，收盘基准以前不回推。期初与期末资产包含净分红应收或现金，内部买卖/分红到账/范围内转账不重复作为外部资金流，实际手续费保留为损益。

只要求基准/期末证券估值及资金流当日 FX；复用已有固定运行时、交易日历、分批请求、退避与暂停队列。区间中不相关证券缺价不阻断资金回报。主金融库 schema7/备份 v6、独立缓存 v3 不变，不引入新的市场依赖或测试财务记录。

金额先按整数分和定点汇率核对，按日期净额聚合后求解。求解在对数增长空间进行缩放求和；常规一次变号资金流由符号变化确认唯一性，交替资金流通过递归导数临界点划分区间隔离根，不使用一个初始猜测或有限网格宣称唯一。多解、无解、近重根、非有限/过大结果以及可靠求解预算不足明确返回原因，不给任选的数字。复杂资金流上限 128 个非零日期项，常规一次变号流不受该项数限制；单次数值预算 200 万项求值。展示最多六位小数，浮点求解不写回金额或账本。

- 范围内/外转账、手续费、修订重新计算、负回报、真实零回报、零天与零本金。
- 仅有端点股价时仍能计算资金回报；TWR 中间缺口仍断开。
