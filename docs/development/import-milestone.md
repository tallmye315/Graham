# 第 7 项：统一 CSV 导入（Issue #8）

## 交付范围

UTF-8（可含 BOM）统一格式 CSV，逗号分隔，支持引号、双引号转义、引号内逗号及换行、CRLF。最多 2 MiB / 2000 数据行。按原始行号逐条预览，校验日期、原币、账户、证券、类型及整批账务。错误或未知事件整批阻止，不默默跳过；确认前主账本不变。

以账户 ID + 外部 record_id 去重，同一身份与原始内容相同为重复，内容不同时为冲突，须走纠错而非覆盖。删除、撤回后仍保留身份；手动记录无外部标识，不能猜测相同金额即重复。确认令牌绑定完整账本与文件，预览后修改文件或账本须重新预览。

支持 deposit、withdrawal、buy、sell、dividend、transfer、exchange、opening。每次确认及批次撤回均为一个即时事务，核对整个最终时间线，失败全部不变。CSV 两端转账/换汇仍是单条关联记录；期初为一行，positions 列用 JSON 数组保存核对持仓。

保留完整原始 CSV、批次、原始行号及内容、原始规范记录和每次手动修正来源。通过导入入口修改、可恢复删除及恢复单条记录；不可更换身份/类型/账户，选错时作废并使用新外部标识重录。导入记录保留核对依据，不提供彻底删除。普通手动记录继续原来的纠错入口。

批次撤回先预览受影响记录和两个账户关联范围，并模拟验证依赖；失败显示原因，阻止不完整撤回。撤回后原批次、全部历史和去重身份保留，可逐条恢复。

## 实现与验证

数据库 schema7 在升级 schema6 前保存一致快照；原有财务记录及历史不变。导入原始文件、条目、修正及撤回历史随加密备份 v6/schema7 保存，兼容 v1–v5。备份验证既检查每个条目对应原始行，也反向保证每个原始身份存在；批次中的重复行可映射到更早批次的原始身份，不能丢失只有来源条目承载的出金。

统一 CSV 使用稳定账户 ID 和外部记录号；确认令牌绑定整份文件及完整逻辑账本。现有精度校验后规范化等值数字，不依靠金额近似猜测去重。内存候选预览、主账本即时事务提交复用同一写入与时间线核对，后台线程处理读取和导入，文件选择使用原生窗口。
