## 生成公开源码包

在项目根目录执行：

```powershell
python -B scripts/export-public-source.py
```

输出位于 `artifacts/public-release/`：

- `Graham-<版本>-source.zip`：只含审核范围内的源码、文档、测试和品牌素材。
- `Graham-<版本>-source.zip.sha256`：压缩包 SHA256。
- `Graham-<版本>-source-manifest.json`：收录文件与逐文件 SHA256，便于核对。

脚本不依赖 Git，也不读取 Git 跟踪状态。它采用明确的顶层文件和源码目录清单，排除本地凭据、财务导出、私人备份、依赖与生成文件；发现疑似密钥、本机绝对路径、账户数据 JSON 或未经审核的图片和二进制文件时停止导出。备份测试中的虚构路径只在指定测试文件内允许。

私人资料留在本地，导出脚本不会修改或删除它们。依赖由开发步骤重新安装，内置行情运行时由打包脚本重新准备；不将上游依赖中的 token 类常量复制到公开源码包。

## 手动上传

1. 将生成的 ZIP 解压到新目录。
2. 检查其中 `Graham/` 的文件，并上传该目录内的内容，使 `README.md` 位于仓库根目录。
3. 不要将 ZIP 当作源码直接上传，也不要直接选择原工作目录；`.gitignore` 不能替代手动打包时的文件筛选。
4. 安装包与源码分开发行，准备发布的每个安装包需单独检查内容和 SHA256。

## 发布前仍需核对

- [ ] 实际上传的内容与生成的文件清单一致。
- [ ] 若选择公开已有仓库，另行核实已有历史、已跟踪文件、Issue、附件与运行日志；源码导出不能移除历史中的文件。
- [ ] 公开安装包的文件版本、运行时、许可证和 SHA256 已核对。
- [ ] Releases 中的附件与 README 安装说明一致；没有附件时保留从源码构建的说明。
- [ ] 完全断网且未安装 Python / WebView2 的干净 Windows 独立验收已完成，或明确保留为未验证限制。

每次导出前仍需复查新增文档、截图和样例数据。模式检查只能帮助识别候选问题，不能代替对账户资料、截图内容和数据授权的人工审核。
