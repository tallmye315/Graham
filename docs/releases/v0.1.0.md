# Graham v0.1.0 — 首次公开源码预览版

Graham 的首个公开源码版本，面向 Windows x64 个人投资记账，采用 MIT 许可证。

## 当前功能

- 多账户、A 股 / 港股 / 美股，以及 CNY / HKD / USD 多币种记录与汇总。
- 股票和 ETF 买卖、税费、移动加权平均成本、已实现及未实现盈亏。
- 入金、出金、内部转账、换汇、分红和期初快照。
- 统一 CSV 导入、预览校验、重复检查和批次撤回。
- 行情与汇率缓存、多币种估值、按市场与原币展示的今日及累计证券收益、清仓明细。
- 时间加权收益率、资金加权收益率及组合分布和贡献分析。
- 记录修订、作废和恢复、修改历史及密码加密备份。

## 获取与使用

本次为 **源码 Pre-release**。下载 Release 页自动提供的 Source code ZIP / TAR，按照 [README](../../README.md#开发与构建) 准备依赖并构建；本次不提供预编译安装包。

## 已知限制

- 主要支持 Windows x64；完全断网、无 Python / WebView2 的干净 Windows 安装仍待独立验收。
- 免费行情可能延时、缺失或限频；不提供券商自动登录、交易同步和下单，券商专用文件格式尚未适配。
- 历史数据不足或公司行动未核对时，部分收益结果不可完整还原。
- 本地账本未加密；导出备份使用密码加密，密码由使用者保管。

本版本适合评估和从源码构建。重要记录请保留独立备份，市场数据与计算结果用于核对，不构成投资建议。
